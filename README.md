# BlastNexa: Block Puzzle

Gioco Android originale (versione di sviluppo 0.9). Repository destinato alla compilazione con GitHub Actions.

**Stato:** la sorgente dell'app deve ancora essere caricata nel repository. Una volta aggiunti i file del progetto, il workflow `.github/workflows/android-debug.yml` genererà l'APK di prova e, solo dopo configurazione della chiave di firma privata, l'AAB firmato per Google Play.

Non inserire mai password o file `.jks` nel repository.
